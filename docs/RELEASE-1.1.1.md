# 1.1.1 发布记录

本版统一角色操作：左键点击、Enter或Space只触发回应，主动打开功能卡片改为右键菜单。角色脚下的计时和其他卡片旁的到期徽标只显示信息，不再左键跳转；已开启的自动到期提醒继续提供确认和稍后操作。

## 发布内容

- 保留长裙、礼裙与原创水滴三种静态形象，增加长裙动态、短裙动态两套视频角色。
- 长裙：挥手5秒、喝茶5秒；短裙：眨眼摆尾循环4秒、挥手5秒、喝茶7.5秒。
- 原创交互控制：呼吸、靠近、拖动与放下反馈；视频替换、结束恢复待机、后台暂停、减少动态、实际透明通道探测及失败/超时回退。
- 喝茶由已确认的喝水事务触发，动画结束不重复记录。角色左键不会切换已有卡片，也不丢失草稿或确认框。
- 外观偏好使用v7，兼容v6/v5/v4及旧v3格式；保留原有角色、位置、大小、透明度和隐私设置，隔离旧标签写入。

素材均来自用户提供的图片和视频，由本项目独立处理和播放，不依赖其他宠物插件。原片裁掉的鞋尖、尾尖未补画，细发丝和运动边缘可能仍有少量抠像痕迹。用户素材不自动适用代码MIT许可，见 [来源说明](../assets/animations/NOTICE.md)。

五段内置视频合计约7MiB，压缩安装包约15MiB。资源内嵌客户端，首次加载量相应增大；关闭动作停止播放，不会移除这些资源。长裙独立待机、Live2D和外部模型包导入尚未提供。

## 验证

- Node.js依赖锁定安装及完整 `npm run check`：格式、生成物一致性、146项测试、JavaScript语法和实际npm打包清单。
- 使用实际1.1.1压缩包在隔离Harness 0.2.1-rc.5、Chromium 156.0.8078.4中安装并验证客户端版本。
- 五种形象的左键、Enter/Space仅回应，倒计时不导航；右键菜单正常打开五种卡片。左键不切换已打开卡片，不干扰草稿与确认框；拖动无误触，拖动后仍能键盘互动。
- 到期徽标只提示，从右键菜单进入喝水；自动到期气泡确认只记录一次，同源双标签页只显示一个到期提醒。320px窄屏菜单与卡片边界通过。
- 实际透明视频解码、预览取消/应用、刷新恢复；短裙连续循环两轮保持同一视频节点；挥手/喝茶结束回待机，7.5秒喝茶不被提示文字到期打断，不重复记录。
- 后台、减少动态、免打扰、拖动与关闭动作的媒体清理与回退；v7迁移、新旧标签隔离及新标签角色同步沿用本轮已完成的浏览器验证。

真实Safari、Firefox、iOS和Android未单独验收，不将Chromium模拟视口等同于真实设备测试。

## 更新

通过Harness插件管理器更新到dsh-offwork@1.1.1，然后刷新已有Harness标签页。右键角色 → 外观 → 角色形象，可选择长裙动态或短裙动态并应用。原有角色选择不会自动替换。

薪资仍保存在Harness Host，喝水记录仍保存在浏览器IndexedDB。原有数据与版本升级独立保留。
