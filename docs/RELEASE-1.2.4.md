# 1.2.4：移除会话日志与兼容旧版 Harness

## 修复

- 删除插件注册的 `/offwork-clock` 斜杠命令。旧客户端读取配置时会自动执行该命令，导致会话中反复出现 `offwork-clock` 与设置 JSON。
- 当前界面只使用同源私有设置接口，正常打开、切换卡片和保存配置不会写入会话。
- `offwork_clock` 代理工具仍保留；只有用户在设置中显式开启代理访问并主动调用时，结果才可能进入会话记录。
- 最低 Harness 版本从 `0.2.2-rc.1` 下调为 `0.2.1-rc.5`。

## 兼容性验证

- 在隔离的 DSH **0.2.1-rc.5** 中安装并加载 1.2.4，页面显示 `data-version=1.2.4`，设置接口 HTTP 200、配置正常，无页面错误。
- 在 DSH 0.2.2-rc.1 中继续通过原有 187 项测试与实际浏览器回归。
- 未改变薪资、喝水、抽烟、计时、收尾和外观存储。

## 升级提示

刷新所有旧标签页。旧版页面如果仍打开并调用已删除的命令，会提示命令不存在；刷新到 1.2.4 后恢复正常，并停止产生这些会话日志。
