## 抠像与统一画面

结合本机u2netp前景参考和白底连通区域分析，保护白色杯子、裙摆、皮肤及饰品，再处理透明边缘颜色。人物整段使用固定缩放和留白，没有逐帧裁切居中。

三段视频统一为400×640、24fps、VP9透明WebM，无音频，总计约3.87MiB。人物比例保持不变。独立静态回退图为640×1024，取自待机首帧，取景一致。

原片部分时刻鞋尖或尾尖触边、截断，新增留白不会恢复已缺失的像素，未做补画。细发丝与快速运动边缘仍可能有少量抠像痕迹。

## 验证

- 三段输出的开头、中间、结尾均实际解码检查alpha，透明与不透明区域同时存在；不是只检查文件扩展名或容器标签。
- 持杯图为1280×1920 RGBA，杯子中心保持不透明；浅色和深色背景均做过合成检查。
- 待机循环首尾处理帧的平均通道差异约0.0256/255，时间映射在循环边界速度平缓；浏览器连续循环两轮保持同一个视频节点。
- 146项项目检查通过。隔离Harness + Chromium验证待机→挥手→待机、待机→喝茶→待机，喝茶不因提示文字到期中断，播放结束不会重复打卡。
- 验证后台、减少动态、免打扰、拖动的暂停与恢复；媒体失败回退可见，不进入重复加载循环；原长裙形象回归通过。
- 外观偏好迁移到v7，兼容v6/v5/v4，保留已有角色与其他设置；旧标签页不能覆盖新短裙选择。

## 使用

1.1.1中，右键角色 → 外观 → 角色形象 → 鲸蓝少女 · 短裙动态 → 应用外观。

短裙正常状态循环待机，点击播放挥手，喝水打卡成功后播放喝茶，结束恢复待机。进入免打扰等安静状态停止自动待机。本批素材随1.1.1提供，发布与验证见RELEASE-1.1.1.md。

素材包中的preview.html可查看透明视频并切换背景。原素材权利归相应权利人，不自动适用项目代码的MIT许可。
