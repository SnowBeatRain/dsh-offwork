# 1.2.0：下班搭子四阶段本地候选版

状态：本地候选版本，尚未发布到 GitHub/npm。版本号表示本次代码与安装产物，不表示完成了两周用户留存实验。

## 从哪里开始

刷新所有 Harness 标签页，点击人物脚下或小卡片中的 **搭子菜单**。菜单提供提醒、计时、收尾、设置、外观、备份六个页面。原来的右键菜单、喝水、抽烟与薪资设置继续保留。

### 1. 到点提醒与快捷入口

- 抽烟、喝水、自定义计时与下班收尾共用提醒投递层。同一时刻只自动呈现一个操作卡，其他提醒可在菜单中查看。
- **关闭**只收起当前提示，不记完成、不重开计时；到期记录仍可查看。
- **稍后10分钟**明确推迟下一次提示；**重新计时**开始新一轮。
- 喝水按钮确认成功后才记账；动画和声音不作为数据保存成功的依据。
- 自动提示不主动抢输入焦点。设置中可以测试一张真实操作卡，测试不改变计时或记录。

### 2. 提醒、计时与数据

- 提示音与后台浏览器通知默认关闭；声音提供试听，浏览器拒绝通知时显示错误并保留页面提醒。
- 统一免打扰可静音全部新提示30分钟，提前结束或到期后恢复；不修改原始截止时间。
- 最多8个独立的具名计时，范围1–1440分钟。原抽烟计时继续使用原数据库与设置。
- 配置界面直接调用同源Host接口，不需会话，不再写入会话操作记录。接口同时校验Harness登录身份、owner权限、Origin与自定义请求头，未认证请求拒绝读取或写入。
- 薪资配置迁至 `$DSH_HOME/storages/dsh-offwork/settings.json`，旧包目录 `data.json` 保留；首次迁移校验数据，只在新文件不存在时创建。
- 代理工具访问作息/薪资默认关闭，需要在设置中显式允许；手动会话命令仍会把结果写入会话。
- 浏览器备份包含喝水、抽烟、新计时、收尾笔记、主题、人物图片及原外观偏好；不含薪资。薪资可单独导出/恢复。
- 恢复先展示摘要；确认时检查预览后是否有用户数据变化。恢复前备份既下载为JSON，也保存在独立的浏览器恢复库中，可以再次下载。
- 跨多个旧数据库的恢复不是单个原子事务；并发更改会中止并显示错误，不能把部分恢复显示成成功。恢复时应暂停其他标签页的操作，必要时用恢复前备份回退。

### 3. 下班收尾

- 可选下班前0/5/10/15/30/60分钟提醒；跨午夜按原计薪引擎的班次开始日期归属。
- 填写“今天完成了什么”“明天第一件事”，可以留空；草稿和已结束状态持久保存。
- 切换标签或关闭前保护未保存笔记；多标签修改冲突会提示重新打开，不覆盖另一页面记录。
- 展示上次留给自己的下一步及最近收尾记录。
- 结束今天只关闭该班次的收尾提醒，不停止全天喝水、自定义计时或DSH代理任务。
- 每日喝水与计时确认只从本版本开始记录；不倒推旧历史。记录最多1500条、保留90天，收尾最多120天。
- 可选择一个DSH会话，在其本轮运行时暂缓喝水/收尾提示，最多2分钟。只读取宿主目录中的 `running` 状态，不读取会话正文；状态不可用时退回普通时间提醒。
- 页面输入期间也可暂缓喝水/收尾；固定独立计时仍按用户选择的截止时间提示。

### 4. 个性化外观

- 导入5MB以内PNG、WebP或JPEG，校验文件签名并通过画布转换成有界PNG；不执行SVG、脚本或外部模型。
- 提供裁切缩放与水平/垂直位置预览，点击“应用人物”才替换；取消不会改变已保存角色。
- 支持宿主主题、雾紫、海蓝、玫瑰、石板灰；卡片字号/宽度90–120%，人物大小继续独立调整。
- 可随时停用自定义人物并恢复内置外观；图片保存在本浏览器，随浏览器备份导出。
- 静态图不会自动生成眨眼或Live2D。原动态角色、按需视频、后台暂停和减少动态设置继续保留。
- Logo采用已确认的斜对角“人物＋倒计时”方案。

## 已知边界

- 需要保持页面打开才能投递页面提醒、声音和浏览器通知。后台可能受浏览器节流；关闭所有页面不保证准点通知，重开后恢复到期状态。
- 系统通知需要HTTPS/localhost、浏览器支持与用户授权；提示音需要用户交互解锁。自动化验证不能代替真实操作系统通知中心和扬声器听感验收。
- 浏览器数据按同源存储，不自动同步到其他设备，不上传笔记或图片。清理站点数据会清除这些记录。
- 暂缓会话仅为只读状态实验，不推断专注效率，也不更改会话或代理工作流。
- 本次实现四个阶段的功能；市场规划中的10–15人两周试用、留存和付费意愿验证尚未进行。

## 维护结构

- `companion-state.js`：提醒投递、计时、收尾、记录和恢复的纯状态逻辑。
- `companion-app.js`：六个页面、浏览器存储协调、声音/通知和导入导出。
- `companion-image.js`：有界图片解码及裁切。
- `settings-api.js`：同源私有配置接口、代理访问策略。
- `index.js`：兼容原命令与工具，稳定存储迁移。

不直接修改生成的 `client.js`；运行 `npm run build`。发布前运行 `npm run check` 并复核实际安装包。
