# 1.2.2：页面收拢与信息层级

已发布到 GitHub 与 npm；1.2.3 仅修订发布文档。

## 主要调整

- 下班卡片只保留计时、班次详情、收尾入口和收入明细。刷新与作息设置不再作为并列文字按钮，设置入口放到卡片右上角。
- 卡片标题会跟随状态显示“上班倒计时 / 下班倒计时 / 本班已完成 / 今天休息”。
- 外观页的角色选择在主区域，大小、透明度和动作收进“显示与动作”；预览高度缩短，主题、卡片尺寸和自定义人物统一通过底部“应用”保存。
- 设置页按“入口 / 提醒 / 高级”分层：作息薪资、喝水间隔、备份恢复是清晰的行入口；提示音、通知、免打扰和下班提醒集中展示；测试提示与代理权限折叠在高级设置。
- “全部免打扰30分钟”使用明确的按钮样式；链接箭头不再混入按钮辅助名称。
- 人物卡片不再长期显示“喝了一杯”。只有喝水提醒到期时才显示快捷记录；平时从喝水卡片操作。
- 自定义计时运行中仍显示在人物脚下，点击回到计时卡片。

## 验证

- 187项Node测试通过，格式、生成物、语法和打包检查通过。
- 隔离Harness Chromium回归：计时/喝水/收尾/外观/备份、未保存保护、到点稍后、非宠物模式、快捷入口、320/390/640视口和触屏深色主题。
- 实际 xxy 环境加载 `data-version=1.2.2`，设置接口 HTTP 200，页面无运行错误。
- 旧薪资、喝水、抽烟、计时和外观数据沿用；不清理站点数据。
