# 1.1.2 发布记录

本版将喝水提醒改为全天自然时间，并整合独立喝水/抽烟计时、紧凑小卡片、简洁详情页和动作试播。发布状态以文末核验结果为准。

## 用户可见变化

- 喝水提醒不再跟随上下班、午休或工作日。例：17:30开启60分钟，即使18:00下班，仍在18:30到期。没有薪资配置或会话也可以使用。
- 饮水计数延续保留，不随班次自动清零；暂停需手动恢复，免打扰可跨下班和午夜。“稍后”是自然时间10分钟。
- 独立喝水、抽烟倒计时及角色脚下的统一计时概览。抽烟默认60分钟，手动开始，可暂停/继续、重启或停止。
- 非宠物模式默认224×94小卡片，状态与主计时横排，水滴/香烟计时在下一行，收入默认只显示眼睛入口。无有效倒计时时显示状态。
- 简化各功能页，提醒设置位于喝水页标题栏；免打扰、记录管理、班次详情和高级配置按需展开，保存入口保持可达。
- 外观动作试播独立于已保存角色与喝水记录。取消、换角色、后台、动作关闭与减少动态效果都会清理播放。
- 视频从同源Host按需加载，支持内容指纹缓存、GET/HEAD、ETag与单段Range。客户端约0.9MB，压缩包约8MiB；现有素材不重编码。
- 修复加载期间宠物展示、定时提醒入口、草稿恢复、首帧透明度误判与动作交接等体验问题。

## 升级与数据

更新插件后请刷新所有打开的Harness标签页。版本标记、源码生成物、包清单和锁文件统一为1.1.2。

喝水IndexedDB沿用数据库名`dsh.offwork-clock.hydration.v1`，数据库版本升为2，新仓库`wall-clock`使用schema3。原schema1/2记录在事务中迁移，保留原开关、间隔、次数、暂停、有效免打扰与近期操作ID；原始`state`快照保留。能够对应原班次时转换剩余分钟；过去班次或不可还原的时间信息从首次迁移开始一个完整间隔。

旧页面的版本1数据库写入会被拒绝，以免覆盖新规则的数据；刷新后恢复。迁移标记避免重置或删除当前记录后重新导入旧次数。未知或损坏数据不自动覆盖，存储失败时提供恢复入口。详情见 [喝水规则](HYDRATION.md)。

薪资仍在原Harness Host配置中；抽烟记录使用独立IndexedDB，外观继续使用v7偏好。不改变已有薪资、工资隐藏、角色和位置选择。

## 验证范围

- 锁定依赖安装、格式、生成物一致性、171项Node测试、36个JavaScript文件语法与56个打包文件白名单检查。
- 实际1.1.2安装包在隔离Harness 0.2.1-rc.5及Chromium中验收，核验页面版本。
- 真实1.1.1旧客户端与新客户端同源升级：保留记录和剩余时间，原始记录不覆写，旧客户端不能写入新数据。
- 全天提醒、午休计时、自然稍后、跨下班免打扰、长期暂停、修改作息不重排、无会话/无配置/Host故障与慢读、数据恢复与双标签去重。
- 简洁详情页、间隔验证与草稿保护、隐私、计数管理隔离、抽烟控制、薪资设置保存；320/390/640视口下的边界及保存可达。
- 动作试播隔离、真实视频与海报对齐、取消清理、休息日完整7.5秒喝茶且只记录一次。

真实Safari、Firefox和移动设备未单独验收；模拟视口不等于真机。现有视频中的原片裁切及少量边缘痕迹未重绘，长裙独立待机、Live2D和外部模型导入仍未提供。
