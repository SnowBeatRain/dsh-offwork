# 数据与隐私

## Harness Host

作息与薪资保存在运行 Harness 的机器：

`$DSH_HOME/storages/dsh-offwork/settings.json`

未设置 `DSH_HOME` 时使用 `~/.dsh`。保存采用原子替换，权限 `0600`。首次读取会校验旧插件目录 `data.json` 并迁移；旧文件保留，损坏文件不会被默认值覆盖。

代理工具访问该文件默认关闭，需要在「设置 → 高级设置」中显式开启。界面保存不写入会话记录。

## 浏览器

以下数据保存在当前浏览器，不上传服务器：

- 喝水设置、计数与提醒状态：IndexedDB。
- 抽烟计时和自定义计时：IndexedDB。
- 下班收尾记录：IndexedDB。
- 角色、位置、大小、透明度、主题、工资隐藏和自定义图片：localStorage/IndexedDB。

同源多标签页会同步提醒和计时。清除站点数据会清除这些记录。浏览器禁止存储时，界面会提示并暂停自动提醒。

## 备份

「设置 → 备份与恢复」可导出浏览器数据，包含喝水、计时、收尾笔记、外观和自定义图片，不含薪资。

薪资需要单独导出，文件包含真实金额，请自行保管。恢复前会生成回退备份；恢复不是跨多个数据库的单个原子事务，恢复时应暂停其他标签页操作。

## 会话记录

- 界面读写不进入会话记录。
- 插件不注册斜杠命令。
- `offwork_clock` 代理工具只有开启权限并主动调用时才会产生记录。
- 工资隐藏只影响界面显示，不删除已经保存的数据或历史记录。
