# 计薪规则

金额均以人民币（CNY）显示，表示按配置估算的税前收入。

| 项目           | 计算方式                        |
| -------------- | ------------------------------- |
| 月薪模式的日薪 | 月薪 ÷ 月计薪天数               |
| 日薪模式的日薪 | 直接使用填写的日薪              |
| 有效时薪       | 日薪 ÷ 扣除无薪休息后的班次时长 |
| 本班已赚       | 日薪 × 已完成的有效计薪比例     |

示例：月薪 10,000 元、月计薪天数 21.75 天、09:00–18:00，并扣除 12:00–13:00 无薪休息时，日薪约为 459.77 元，有效时薪约为 57.47 元。

- 金额按分截断，不四舍五入；计薪比例使用有理数计算，减少浮点误差。
- 无薪休息期间收入暂停增长，下班倒计时继续。
- 下班时间早于上班时间视为次日下班；工作日按班次开始日判断。
- 夜班完成后，上一班金额保留到新一班开始。
- 时间使用配置中的时区；夏令时按实际经过的秒数计算。
- 当前支持每班一段无薪休息，不包含税费、加班费、法定节假日调班或复杂轮班规则。
