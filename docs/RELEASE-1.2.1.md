# 1.2.1：交互收拢与卡片联动

这是对1.2.0本地候选版的体验修订，尚未发布到GitHub/npm。

## 这次怎么用

- 人物脚下的下班时间、喝水和抽烟时间都是直接入口，点击进入原来的对应卡片。
- 小卡片底部的水滴按钮可以直接记一次喝水；右侧的“…”只打开上下文菜单。
- 抽烟计时卡片同时管理原抽烟计时和其他具名计时；运行中的自定义计时会显示在人物卡片下方，点击它可回到同一张计时卡片。
- 下班卡片里可以打开今日收尾，写下明天第一件事。保存后继续切换页面时仍会有未保存保护。
- 外观页现在把内置人物、主题、卡片大小和自定义图片放在同一页。所有修改都先预览，点击“应用外观”一次保存；取消不会留下半套修改。
- 设置卡片只保留提醒、声音、免打扰和到作息/喝水/备份的入口。低频选项收进“高级设置”。
- 备份、喝水间隔、作息薪资从设置卡片进入，返回时回到设置卡片，不会继续打开新的独立导航层。
- 提醒卡固定在人物旁边显示。稍后后，人物旁和计时卡片会显示下一次提醒剩余时间。

## 设计调整

1. 常用动作保留在人物和现有卡片上，减少独立菜单。
2. 同一份数据只有一个主要编辑入口。
3. 新增内容通过现有卡片扩展，避免页面数量继续增加。
4. 取消和返回优先保留用户正在编辑的上下文。

## 验证

- `npm run check`：187项Node测试通过，安装包和语法检查通过。
- 隔离Harness浏览器验证：一键喝水、抽烟/喝水直接进入卡片、自定义计时联动、外观取消/应用、收尾草稿、备份返回、到点稍后、非宠物模式和深色触屏布局。
- 验证视口：320、390、640和1280像素；触屏配置下主要按钮至少40像素高。
- 旧喝水计数、抽烟计时、作息薪资和外观偏好均使用独立数据做验证，没有清空用户数据。
