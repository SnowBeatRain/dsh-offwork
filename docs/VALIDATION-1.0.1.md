# 1.0.1 浏览器与安装验证记录

验证日期：2026 年 11 月 4 日。

## 环境

- 系统：Linux ARM64。
- Harness：`0.2.1-rc.5`，独立临时 `DSH_HOME` 下的 Web 配置。
- 插件：本地 `1.0.1` npm 压缩包，通过 `dsh plugin --profile web add <压缩包>` 安装。
- 浏览器：Playwright 驱动的 Headless Chromium `156.0.8078.4`。
- 窗口：1440 × 1000，并检查 390 × 844 下的小条位置。
- 数据：临时工作区和会话，示例月薪 12,000 元、月计薪 20 天，09:00–18:00，12:00–13:00 无薪休息，时区 Asia/Shanghai。
- 时间：浏览器时钟从 `2026-11-04T06:30:00Z` 开始，在检查过程中推进，覆盖工作时段倒计时更新。服务端使用实际时间。

未使用现有用户的工资配置、工作区、会话、模型凭据或授权链接。不调用模型 API。

## 本轮发现并修复

- 设置中的“显示工资”和计薪方式按钮被外围标签影响辅助名称，补充明确的 `aria-label`。
- 透明度默认值为 82%，原 5% 步长导致原生滑块取值为 80%；调整为 1% 步长，使控件与实际设置一致。
- 客户端版本标记更新为 `1.0.1`。

## 范围限制

这次检查验证的是上述 Linux Headless Chromium 和 Harness 组合，不等同于完成所有浏览器或操作系统的人工验收。Safari、Firefox、触摸手势、减少动态效果和长时间真实后台节流仍需后续实际使用反馈。

夜班、休息、时区、夏令时、金额精度、损坏配置和命令 / 工具一致性继续由已有自动化测试覆盖；本轮没有把所有这些场景重新作为浏览器交互运行。

浏览器验证使用临时安装的 Playwright，不增加项目运行时依赖。发布前仍需通过 `npm run check` 与 GitHub CI；发布后另行确认 npm 元数据和压缩包可下载。
