# 独立 Harness 宠物插件：方向与边界

状态：需求澄清与设计记录。此前“基于现有 dsh-pet-offwork 做适配”的建议已被用户明确否定，不再执行。

## 已确认目标

- 做我们自己的独立 DeepSeek Harness 插件，角色在 Harness 页面内悬浮。
- 自己实现宠物展示、模型加载、动画状态、拖动、气泡和功能面板。
- 不在别人的宠物插件上修改、套壳或开发分支；不以 dsh-pet、dsh-pet-offwork 为运行依赖，不调用其宿主服务来实现核心功能。
- 现有第三方宠物安装与本地定制包不属于本任务的修改范围，不修改、替换或卸载。
- 不开发系统桌面宠物，不引入 Electron 客户端。

“新的独立插件”描述产品与实现的独立性；用户尚未要求另起 npm 包名或重置版本。当前继续在我们自己的 dsh-offwork 开发分支整理实现，保持 1.0.1、不推送、不发布，后续命名与发布另行决定。

## 资源与插件代码分开

用户希望达到 dshpet 类插件的卡通角色效果，并能使用这类人物模型。这可以通过独立的资源加载器实现，不要求依赖提供示例的插件。

- 可以参考公开的模型描述格式，设计兼容资源的解析与校验。
- 具体角色文件只作为可替换的资源包，不执行其中的插件代码。
- 素材采用原创或获得适当授权的资源；不因文件存在于已安装插件就自动复制进我们自己的包。
- 精灵图、序列帧、透明视频和 Live2D 需要各自的渲染支持，不能宣称支持一种格式就能使用全部模型。
- 第一阶段支持的资源格式待实现设计收敛；本轮澄清没有承诺一次完成所有渲染器。

## 自主实现结构

1. 复用我们已经实现并验证的 clock.js、hydration.js 与事务存储，继续管理计薪、班次、喝水、免打扰。
2. 独立的宠物状态映射：把真实业务状态和确认过的用户操作转成角色姿态、气泡与动作。
3. 独立的模型资源层：资源描述、校验、加载、替换、渲染器选择和失败回退。
4. 独立的宠物展示层：页面悬浮、拖动、缩放、显隐、边界约束和无障碍。
5. 独立的交互面板：点击宠物后提供喝水打卡、免打扰、倒计时、工资与设置。

当前 SVG“小歇”及 companion.js 是我们自己的表现层原型，可用于开发与失败回退；最终交互以页面内独立宠物为主体，不继续把角色限定在原计时卡片内部。

保持已有多标签页单提醒、免打扰、午休、夜班、工资隐藏和浏览器数据边界。现有设置和记录不能因为更换角色展示而丢失。远眺、心情后续接入同一套自主业务与表现模块。

## 调查结论的用途

此前已查阅 PC2005-cloud/dsh-pet、zhu1090093659/dsh-pet、DamonKoy/dsh-web-ui 的公开说明，并发现测试环境存在第三方宠物包。它们只作为体验和公开资源格式的参考，不作为开发基底。关于 Electron 桌宠及对现有定制包进行修改的路线均已取消。

本次只更新方案；未修改第三方插件或当前运行功能。
