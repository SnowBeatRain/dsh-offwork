## 本轮验证边界

用户反馈常用环境使用正常，未提供具体系统和浏览器版本。本轮另行在隔离环境中完成有明确版本和操作记录的浏览器验证。Safari、Firefox、触摸手势、长时间后台等未覆盖场景不标记为已验证。
