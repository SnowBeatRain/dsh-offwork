# 动作视频素材

whale-greet.webm 与 whale-drink.webm 来自用户本轮提供的挥手、喝茶视频，分别对应文件站文档 f76a34ba-6a70-423a-8386-933275bde57f 和 f3235c90-7f69-4f64-bbca-f4aeb67c83b2。原片均为5秒、768×1152、24fps、白底MP4。

处理在本机完成：结合u2netp前景判断与白底连通区域去背景，保护白裙和杯子，处理边缘颜色，整段采用固定缩放及留白，不逐帧裁切居中。输出为480×768、24fps、无音频的VP9透明WebM。对应静态回退图取自处理后的挥手首帧，使用相同取景。

原视频已截掉的鞋尖或尾尖没有重绘恢复；部分发丝和运动边缘仍可能有抠像痕迹。本次按提供者的1.1.1发布指示随插件分发，保留这些素材限制。

ornate-idle.webm、ornate-greet.webm、ornate-drink.webm来自用户补充的短裙视频，文档ID分别c77cae16-737e-48a5-b26e-1e579468dd59、7482c445-c5e9-4735-8b63-d1dfa378f4e6、42d37cf6-8445-4927-a440-9f45981a2408。持杯关键帧52b82668-278d-4d8b-976d-70e347f56180另行导出透明PNG，不随运行包加载。

短裙待机取原片前约1.67秒避开额外闪光，用平缓往返时间映射形成4秒循环；挥手取前约2.25秒并补回程成为5秒；喝茶原片实际10秒，去掉多余停留后保留7.5秒。三段输出400×640、24fps透明VP9，无音频。对应静态图取自处理后的待机首帧。完整处理说明见 ../../docs/ORNATE-ASSET-ANALYSIS.md。

alpha-probe.webm 是本项目自行生成的16×16透明度测试图视频，用来检查浏览器实际解码alpha的能力，不含人物素材。

用户视频及其处理结果不自动适用项目代码的MIT许可，原始素材权利归相应权利人。
